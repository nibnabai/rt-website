---
title: Upload a batch
description: Upload up to 50 full conversations at once, with POST /v1/support/conversations/batch.
---

Upload whole conversations in bulk. This is how you bring history into RipeText when you don't run an adapter, and it's also useful for backfilling a system RipeText can't reach.

```
POST https://api.ripetext.com/v1/support/conversations/batch
```

- **Scope:** `support:ingest`
- **Signature:** required, see [signing requests](/docs/api/signing)
- **Rate limit:** 10 requests per minute per integration, 50 conversations each

## Request

| Field           | Type  | Required | Description                                                                   |
| --------------- | ----- | -------- | ----------------------------------------------------------------------------- |
| `conversations` | array | yes      | 1 to 50 full [conversations](/docs/api/support/reference/conversation-format) |

Every conversation must be complete: a reference carrying only an `external_id` is rejected here, since a batch is never fetched back from your adapter.

```js
import { createHmac } from 'node:crypto';

const rawBody = JSON.stringify({ conversations });
const timestamp = String(Date.now());
const digest = createHmac('sha256', process.env.RIPETEXT_SIGNING_SECRET)
  .update(timestamp)
  .update('.')
  .update(rawBody)
  .digest('hex');

const response = await fetch(
  'https://api.ripetext.com/v1/support/conversations/batch',
  {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${accessToken}`,
      'Content-Type': 'application/json',
      'X-RipeText-Signature': `t=${timestamp},v1=${digest}`
    },
    body: rawBody
  }
);
```

  <CodeBlockTab value="python">

```python
import hashlib
import hmac
import json
import os
import time

import requests

raw_body = json.dumps({"conversations": conversations}, separators=(",", ":"))
timestamp = str(int(time.time() * 1000))
digest = hmac.new(
    os.environ["RIPETEXT_SIGNING_SECRET"].encode(),
    f"{timestamp}.{raw_body}".encode(),
    hashlib.sha256,
).hexdigest()

response = requests.post(
    "https://api.ripetext.com/v1/support/conversations/batch",
    data=raw_body,
    headers={
        "Authorization": f"Bearer {access_token}",
        "Content-Type": "application/json",
        "X-RipeText-Signature": f"t={timestamp},v1={digest}",
    },
    timeout=60,
)
```

## Response

`202 Accepted`:

```json
{
  "accepted": 2,
  "workflow_ids": [
    "webhook-ingestion-<org>-integrationapi-<slug>-batch:ticket-1234",
    "webhook-ingestion-<org>-integrationapi-<slug>-batch:ticket-1235"
  ]
}
```

`accepted` is how many conversations were taken, one workflow each.

## Errors

| Status | Code                                                                      | Meaning                                                               |
| ------ | ------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `400`  | `schema_violation`                                                        | A conversation is malformed, or there are more than 50 in one request |
| `401`  | `unauthorized`, `token_revoked`                                           | The access token expired or its credential was revoked                |
| `401`  | `missing_signature`, `invalid_signature`, `signature_expired`, `replayed` | See [signing](/docs/api/signing)                                      |
| `403`  | `insufficient_scope`                                                      | The credential lacks `support:ingest`                                 |
| `403`  | `ip_forbidden`                                                            | The request came from outside the credential's IP allowlist           |
| `413`  | `payload_too_large`                                                       | The body is over 5 MB                                                 |
| `429`  | `rate_limited`                                                            | More than 10 batches in a minute for this integration                 |

## Uploading a large history

- **Watch the size limit before the count limit.** 50 long conversations can exceed 5 MB. If you hit `payload_too_large`, send fewer per request.
- **Ten requests a minute** is 500 conversations a minute at most. Pace your uploads, and back off when you see `rate_limited`.
- **Re-uploading is safe.** Conversations are matched by `external_id`, so a repeat updates the existing one.
