Welcome to the RipeText documentation. Here you'll find guides for connecting your support platform and getting the most out of RipeText.

## Getting Started

RipeText connects to your existing support tools and provides AI-powered insights to improve your team's performance.

### Integrations

We currently support the following platforms:

- **[Crisp](/docs/integrations/crisp)** - Analyze live chat conversations from Crisp
- **[Integration API](/docs/api/support)** - Connect a system we don't support natively by sending us your conversations through the [RipeText API](/docs/api)
- **[Front](/docs/integrations/front)** - Connect your Front inbox to RipeText
- **[GitHub](/docs/integrations/github)** - Import issues from public GitHub repositories
- **[HubSpot](/docs/integrations/hubspot)** - Sync conversations from HubSpot
- **[Intercom](/docs/integrations/intercom)** - Sync conversations from Intercom
- **[Salesforce](/docs/integrations/salesforce)** - Import Service Cloud cases from Salesforce
- **[Zendesk](/docs/integrations/zendesk)** - Import tickets from Zendesk

Each integration guide walks you through the setup process, configuration options, and troubleshooting tips.

## API

Drive RipeText from your own code with the [RipeText API](/docs/api): authenticate, sign your requests, and send us data from any system.
